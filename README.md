# Mini-Webpage


## 📖 Overview

This project is a simple and clean web interface featuring a modern sidebar navigation system. It includes interactive hover effects, icon-based menu items, and a visually appealing background image layout.

The goal of this project is to practice and demonstrate fundamental front-end development skills using HTML and CSS.

---

## ✨ Features

* 📂 Sidebar navigation menu
* 🎨 Smooth hover effects on menu items and icons
* 🖼️ Full-screen background image design
* 📱 Clean and minimal UI layout
* 🔗 Social media icons integration

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome (for icons)

---
